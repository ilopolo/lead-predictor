# LeadScore

A lightweight, privacy-friendly lead scoring tool for sales teams. Paste a lead's details, set your own point values, and get a clear priority recommendation.

## Run locally

This is a dependency-free static site. Open `index.html` in a browser, or serve the folder with any static web server.

## Planned workflow

1. Capture lead attributes.
2. Calculate a transparent score.
3. Review actionable recommendations and recent leads.

## Deployment

The project is configured for static hosting and can be deployed directly to Netlify.
